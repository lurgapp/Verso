# Обновление безопасности Verso 2.0.1 — 7 ноября 2026

Обновление проверено на отдельном окружении и установлено в работающий сервис. Схема PostgreSQL, содержимое статей, ключи владельцев, публичные адреса и объекты S3 сохранены. Перед переключением сделана закрытая резервная копия; восстановление БД и всех объектов проверено в отдельном окружении. Резервные копии и служебные материалы не входят в репозиторий.

## Исправления

- Next.js 16.4.5, React/React DOM 19.3.1, sanitize-html 2.18.1, Zod 4.6.7 и KaTeX 0.19.1. Уязвимая транзитивная deepmerge удалена вместе с обновлением sanitize-html.
- Неиспользуемый оптимизатор Next Images отключён. Маршрут `/_next/image` возвращает 404.
- Передача медиа использует Node API: прежние URL, GET/HEAD, Range и точный Content-Length сохранены. Размер объекта S3 сверяется с ожидаемым до отправки тела.
- FFmpeg/ffprobe получают минимальное окружение без секретов приложения. Используется FFmpeg 9.0.2 с ограниченным набором форматов, протоколами file/pipe и отключённой сетью. Источник проверяется по закреплённому SHA256; подпись релиза проверена при подготовке обновления. Флаги сборки находятся в `scripts/build-media.sh`, сведения об источнике и лицензии — внутри образа.
- Runtime Node.js 22.23.4 на Debian trixie обновлён; npm и другие инструменты установки пакетов удалены из конечного образа. Контейнер работает без root, с read-only корнем, ограничением процессов и отдельными временными файловыми системами.
- PostgreSQL остаётся на версии 16.14 с прежним форматом тома. Системные пакеты обновлены; служебный gosu заменён на su-exec. Пользовательские данные не пересоздаются.
- На рабочем ingress проверены TLS, HSTS, ограничения запросов и доверие к заголовкам адреса клиента только от актуальных сетей Cloudflare. Подмена клиентом forwarding-заголовков проверена отдельно. Публичный compose рассчитан на самостоятельную настройку ingress согласно `docs/deployment.md`.

## Проверки

- `npm audit`: 0 известных уязвимостей, включая devDependencies.
- TypeScript и production-сборка: успешно.
- Живые главная и прежние демонстрационные статьи проверены в Chrome при ширине 390 и 1440 px: нет ошибок JavaScript и горизонтального переполнения; четыре изображения загружаются, оба видео воспроизводятся. Проверка не создавала пользовательских публикаций.
- Модульные тесты: 89; интеграционные: 24; браузерные: 60 — все прошли.
- Проверены сохранённые ключи владельцев, история, прежние публичные страницы, побайтовая сохранность исходных объектов S3, HEAD/Range, обработка GIF/WebP/APNG/JPEG/MP4/WebM и дополнительных AV1/HEVC/AAC файлов.
- Финальный runtime образ из `Dockerfile.prebuilt` проверен после восстановления данных, затем установлен в сервис. Полная многостадийная сборка `Dockerfile` отдельно не запускалась.
- При замене PostgreSQL новые HTTP-запросы удерживались временным шлюзом около 2,4 секунды и затем были обработаны. До и после замены сравнивались хеши исходных записей и подключение прежнего тома. Откатные образы сохранены отдельно.

Записи ОС относятся к парам «пакет–CVE», а не к числу уникальных уязвимостей или подтверждённых способов атаки на Verso. Среди оставшихся предупреждений есть системные библиотеки и инструменты с условиями эксплуатации, которые отличаются от использования приложения. Read-only корень, отсутствие root/capabilities, отключённая сеть FFmpeg и минимальное окружение уменьшают доступные возможности атаки, но не заменяют будущие исправления поставщика.

Внешний монитор во время работ фиксировал отдельные сетевые таймауты. Они не подтверждают причину на стороне приложения; непрерывность всех внешних соединений не заявляется. Дополнительный монитор TLS непосредственно на origin выполнил 1074 успешные проверки без сбоев, включая замену БД; максимальное время ответа составило 2417 мс.

Повторять аудит следует на свежей базе уведомлений. Безусловное обновление всех major-версий не выполнялось: изменения проверены на совместимость с существующими данными и поведением сервиса.
