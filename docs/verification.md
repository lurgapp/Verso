# Проверки исходников

```bash
npm ci
npm run db:generate
npx next typegen
npm run typecheck
npm test
npm run build
```

Node.js 22+ и FFmpeg/FFprobe необходимы для полного набора проверок обработки медиа. Dockerfile устанавливает FFmpeg.

Интеграционные и браузерные тесты требуют отдельной тестовой PostgreSQL, S3 и запущенного приложения; команды и ограничения описаны в README. Не направляйте тесты с записью на пользовательское окружение.

Результаты внутренних развёртываний и служебные отчёты не входят в публичный репозиторий.
